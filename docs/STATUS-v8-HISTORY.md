# 当前状态 · v8.0.0 ROS Servo Preview

## 已实现

- 统一源码根目录；v8 客户端及桥接速度配置互锁，保留原界面功能。
- ROS 2 Humble 两个包可编译；真实 MoveIt Servo + 模拟关节执行链路。
- 基座五轴输入、姿态修正、两类速度独立上限、释放减速、关节输出限制。
- 250ms 外部输入/反馈期限、100ms Servo 输出期限、故障锁存、显式恢复与重新按下。
- 模拟记录零位/回零/中止；零位绑定模型标识，旧零位仅备份。
- 接收式 CAN 读取，逐组反馈年龄；SDK 末端与未核验模型 FK 分开展示。
- 独立相机采集进程、环境检查、诊断包、独立目录迁移与回滚说明。

## 已验证（开发电脑，不是 N100）

Windows WPF 测试、Ubuntu 22.04 WSL 中的 ROS 编译与模拟运行。
Windows真实UDP客户端→桥接→ROS Servo→模拟关节→实际模型反馈，低速点动产生位移。
模拟松手后关节速度归零；断链触发故障，恢复通信不自动续动。
完整记录见 TEST_RESULTS.md。每次软件测试的“实际反馈”指模拟关节/FK，不指现场机械臂。

## 接入实机的下一步

先在 N100 跑 preflight，部署只读模式并采集10秒诊断；确认反馈与模型一致。
取得匹配固件的官方 CPV 行为说明，补足 CAN 唯一写入者和底层看门狗证据。
在地面、有可控停止条件下验证模式切换、速度符号、零速保持及停止，再发布新的实机版本。
不要在本预览版新增 `real_motion=true` 直接发送；现有 `real` 启动入口明确拒绝。

## 已知实现限制

- Python 普通 Linux 控制循环不是硬实时；100Hz是目标，超时记录并处理。
- 只读驱动不会主动查询固件，因此 firmware=unknown。需现场提供固件信息。
- 官方碰撞排除表用于标准 Piper 模拟；仍需随真实型号复核。
- 未配置3D环境传感器，MoveIt启动的 Octomap 提示对此是预期的；不表示已具备环境避碰。
- 默认没有视频模拟画面，sim 会显示视频缺失，但控制与视频状态独立。
- 旧 v7 的 CAN 驱动文件保留作回归参考；v8 的程序入口拒绝加载它。
