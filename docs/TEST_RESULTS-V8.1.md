## 首次交付的软件验证（历史记录）

## 已通过

- ROS两包构建，含DDS源时间中继、PIPER-L模型审计程序。
- Python回归：桥接87项 + ROS数学/CPV/SDK/模型/配置/迁移49项，共136项通过。
- 官方SDK虚拟CAN：启动仅版本查询、六轴速度无隐式模式帧、发送异常传播、完整固件解析、逐组反馈年龄。
- SDK正运动学与URDF：50组固定随机种子的关节姿态，差异均<5mm/2°；仅数学核对，不能替代实际SDK反馈比对。
- CPV独立进程+假SDK：HTTP显式使能、五秒保持、0.5秒以内单次点动、手动急停、异步日志；最终运行周期p99约10.28ms，最大约11.89ms。
- ROS模拟：MoveIt Servo产生真实关节轨迹，模拟位移1.348mm；松手六轴速度归零；输入过期锁存，恢复通信不续动。
- 暂停Servo进程：检测到servo_output_timeout，恢复进程不自动继续。
- Windows→真实UDP桥接→MoveIt→模拟反馈：点动1.370mm，记录位姿回零残差0.472mm；ACK指标、版本互锁、手动急停、显式恢复、断链检查通过。
- Windows SmokeTests 与 UiTests通过，含鼠标/触摸捕获取消、调速清零、对角限速、保留界面功能、平板布局；截图已检查。
- 环境预检保存了WSL完整安装版本，并检查MoveIt动态库、Python模块与SDK源码锁。

## 测试中发现并修正

- 新夹爪法兰对腕部1mm安装间距造成持续接近降速：按固定装配邻接关系排除安装对，保留手指对机械臂检查。其余自碰撞接近阈值5mm；现场仍需核验。
- ROS Node自带executor属性与新状态字典命名冲突，已改为cpv_report。
- 接收反馈发生在控制周期起点之后时，旧年龄计算会误判未来数据：按接收工作完成后的单调时钟判断。
- MoveIt消息/资源包有独立版本，不能与MoveIt核心强制同版本：预检现在只比较同源软件家族。
- HTTP管理等待不再占用100Hz网关控制锁。
- 纯平移遭遇姿态偏差时不再拖动姿态参考；追加了偏差场景测试。

Windows与WSL联测使用WSL实际IP。localhost的TCP转发不能代替UDP联通，该次localhost尝试未计为通过。
